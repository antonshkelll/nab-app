# Спроси ССт НАБ: Telegram Mini App

![version](https://img.shields.io/badge/версия-3.0-62122C)
![stack](https://img.shields.io/badge/HTML_·_CSS_·_JS-без_сборки-0B2E0B)
![license](https://img.shields.io/badge/license-MIT-lightgrey)

Веб-приложение внутри Telegram для Студенческого совета факультета «Налоги, аудит и
бизнес-анализ» Финансового университета. Открывается из бота
[@sprosinab_bot](https://t.me/sprosinab_bot).

Демо в браузере: https://app.nablabel.ru (отправка обращений работает только внутри Telegram).

![Экраны приложения](screenshots/hero.jpg)

Дизайн сделан по брендбуку факультета NAB Label: палитра pine / mint / wine / cream,
шрифты Unbounded и Comfortaa, фактура бумаги, наклейки, «звёздочки» бренда.

## Что нового в версии 3

- Мои обращения: статус («новое → в работе → решено»), переписка с командой Студсовета, оценка ответа звёздами.
- Анонсы с записью «пойду / не пойду» и напоминаниями, опросы и новости.
- Пульт администратора (`admin.js`, грузится только у админов): обращения с фильтрами и поиском, рассылки,
  анонсы, опросы, новости с картинками, настройки, дашборд метрик и отчёт за месяц в Excel.
- Статистика без слежки: экраны, нажатия и поиски считаются счётчиками по дням, без привязки к людям.

## Что внутри

- Главная сделана как лендинг: интро с логотипом, бегущие строки, доска-«наклейки» с разделами,
  квест «Шаг 1 из 3» (FAQ → НПБ → каналы), кричалка факультета, фотогалерея, манифест.
- Формы обращений: вопрос руководству (можно анонимно), инициатива, поломка с фото
  (до 5 штук, сжатие на телефоне перед отправкой), тревожная кнопка.
- FAQ-листалка на 27 страниц с ползунком по страницам, разделами и поиском по тексту. Поверх страниц
  лежат 74 ссылки: сайты открываются в браузере, каналы в Telegram, почта копируется,
  пункты оглавления переносят на нужную страницу.
- Карта корпуса: 9 этажей двух корпусов, план двигается и приближается пальцами. Поиск по номеру
  аудитории ставит точку на плане (координаты ~350 аудиторий распознаны с планов).
- Документы вуза (НПБ): листалка и отправка PDF в чат.

## Как устроено

Приложение написано на HTML, CSS и JavaScript без фреймворков и сборки: три файла и папка `assets/`.

- Вместо `history` используется свой стек экранов. Кнопка «назад» Telegram всегда ведёт на предыдущий
  экран, а ссылки вида `#/map` и `startapp=faq` сразу открывают нужный раздел.
- Анимации используют только `transform` / `opacity` / `clip-path` и `requestAnimationFrame`,
  поэтому идут плавно и на слабых телефонах. Учитывается `prefers-reduced-motion`.
- Страницы FAQ загружаются лениво через `IntersectionObserver`: картинка грузится, когда
  страница подъезжает к экрану, а до этого на её месте мерцающая заглушка с правильными пропорциями.
- Жесты карты написаны на Pointer Events: перетаскивание, щипок двумя пальцами, двойной тап.
- Каждый запрос к API несёт подписанный Telegram `initData`, сервер проверяет
  подпись. Вне Telegram формы прямо сообщают, что отправка доступна только в боте.
- Данные (страницы FAQ, ссылки, текст для поиска, этажи карты) лежат в JSON-манифестах в
  `assets/`. Их собирают скрипты из репозитория бота, код приложения при этом править не нужно.

## Структура

```
index.html            каркас, подключение Telegram WebApp SDK
app.js                экраны, навигация, формы, обращения, анонсы, опросы, листалка, карта
admin.js              пульт администратора (подгружается только у админов)
styles.css            дизайн-система и все экраны
assets/brand/         логотипы и фото
assets/faq/           страницы FAQ (webp), links.json, text.json, manifest.json
assets/map/           этажи (webp) и manifest.json с координатами аудиторий
assets/docs/          документы НПБ (собираются на сервере)
assets/fonts/         фирменные шрифты — только на сервере, в репозитории их нет
```

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Внутри Telegram приложение работает вместе с бэкендом
[nab-bot](https://github.com/antonshkelll/nab-bot). На сервере этот репозиторий клонируется
в папку `webapp/` бота, статику отдаёт nginx.
